# Documentation

Read the [live Navi documentation](https://machine-path.mintlify.site).

`docs/mintlify/` is the source for the public documentation site.

| Task | Where to start |
|---|---|
| Edit public docs | Update the relevant page under `docs/mintlify/` and its navigation in `docs/mintlify/docs.json` when needed |
| Validate locally | Run `node scripts/docs-release-check.mjs` |
| Contribute code | Read [`CONTRIBUTING.md`](../CONTRIBUTING.md) |
